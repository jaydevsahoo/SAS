
Q. DIFFERENCE BETWEEN SYMGET AND SYMGETN ?
A: SYMGET reads macro variable values as char
   SYMGETN reads macro variable values as numeric
   
Q. CAN WE CREATE A MACRO VARIABLE USING %LET. IF SO, IS THIS GLOBAL OR LOCAL?   
A. Yes , But it depends where it has been declared. If it is declared inside the %MACRO then it 
   is LOCAL ,otherwise it is called GLOBAL

Q. What is "CALL SYMOUT"?
A. When a Macro variable is passed in Data step we use "CALL SYMPUT",
   However the variable cannot be called inside Data step. We have to call it outside.
   Ex. DATA _NULL_;
   	   CALL SYMPUT("X1",PUT(TODAY(),YYMMN6.)); 	
   	   RUN;
   	   
   	   %PUT &X1.;
   	   
Q. WHAT IS THE DIFFERENCE BETWEEN %EVAL AND %SYSEVALF?
A. Both are used in creating expression, 
   %EVAL goes with integer values
   %SYSEVALF goes with float values
   Ex:
   %LET A=100;
   %LET B=200;
   %LET C=&A.+&B.;
   %PUT &C.;
   
   %LET A1=100.15;
   %LET B1=200.65;
   %LET C1=&A1.+&B1.;
   %PUT &C1.;
   
Q. WHAT IS THE DIFFERENCE BETWEEN SYMGET AND SYMGETN? 
A. SYMGET() will show macro variable value in char format
   while SYMGETN() will show macro variable value in numeric format.
